# 📷 M-Vision Cam

Esta carpeta contiene la programación relacionada con el sistema de **visión artificial de ATOM ArchBot**.

Aquí se irán guardando los códigos desarrollados para la M-Vision Cam, incluyendo pruebas de detección, procesamiento de imagen, comunicación y futuras versiones del sistema de visión principal.

## 👁️ Funciones principales

La M-Vision Cam será utilizada para analizar visualmente el contenido del harnero.

Entre las funciones que se desarrollarán se encuentran:

* Detección de colores.
* Análisis de formas.
* Detección de objetos.
* Filtrado de posibles falsas detecciones.
* Seguimiento de objetos.
* Confirmación mediante varios fotogramas.
* Procesamiento de imágenes.
* Comunicación con el MATRIX Mini R4 mediante UART.

## 📂 Códigos

Los códigos se agregarán progresivamente a esta carpeta a medida que sean desarrollados y probados.

Por ejemplo:

```text
M-Vision-Cam/
│
├── README.md
├── Deteccion_Dorado_V1.py
├── Deteccion_Dorado_V2.py
├── Prueba_UART.py
└── Vision_Principal.py
```

No será necesario eliminar las versiones anteriores que hayan sido útiles, ya que estas también permiten conservar un registro de la evolución del sistema de visión.

> [!NOTE]
> La programación de visión artificial se encuentra en desarrollo y podrá cambiar durante las pruebas de iluminación, posición de cámara y detección de objetos.
