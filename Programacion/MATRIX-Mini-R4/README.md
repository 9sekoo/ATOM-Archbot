# 🧠 MATRIX Mini R4

Esta carpeta contiene la programación desarrollada para el **MATRIX Mini R4**, controlador principal de **ATOM ArchBot**.

Aquí se irán guardando los diferentes códigos utilizados durante el desarrollo del robot, incluyendo pruebas individuales de componentes y futuras versiones del programa principal.

## ⚙️ Funciones principales

El MATRIX Mini R4 será encargado de controlar y coordinar diferentes sistemas de ATOM ArchBot, entre ellos:

* Servomotores del harnero.
* Motores DC de la bandeja.
* Sensores láser.
* Pulsadores.
* Final de carrera.
* Pantallas LCD.
* Sistemas RGB.
* Buzzer.
* Comunicación con la M-Vision Cam.
* Estados generales de funcionamiento del robot.

## 📂 Códigos

Los códigos se agregarán progresivamente a esta carpeta a medida que sean desarrollados y probados.

Podrán existir códigos independientes para realizar pruebas antes de integrarlos al programa principal.

Ejemplo:

```text
MATRIX-Mini-R4/
│
├── README.md
├── Prueba_Servos
├── Prueba_RGB
├── Prueba_Sensores
└── ATOM_Principal
```

> [!NOTE]
> La programación se encuentra en desarrollo, por lo que los códigos y su organización pueden cambiar durante las pruebas del prototipo.
