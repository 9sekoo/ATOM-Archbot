# 📓 Bitácora de desarrollo — ATOM ArchBot

Esta bitácora registra el proceso de **diseño, construcción, programación, pruebas y mejoras de ATOM ArchBot**.

Su objetivo es mantener un registro simple de los avances realizados durante el desarrollo del proyecto, acompañado de fotografías cuando sea necesario.

> [!NOTE]
> Esta bitácora se irá actualizando durante todo el desarrollo de ATOM ArchBot.
> Las decisiones, diseños y soluciones mostradas aquí pueden cambiar a medida que se realicen nuevas pruebas.

# 📝 Cómo agregar un nuevo avance

Para registrar un nuevo día de trabajo, se puede copiar la siguiente plantilla:

```markdown
## 📅 DD/MM/AAAA

### 🔧 Trabajo realizado

- 
- 
- 

### 📸 Fotografías

![Descripción de la fotografía](Fotos/nombre_de_la_foto.jpg)

### 🧪 Pruebas realizadas

- 

### ⚠️ Problemas encontrados

- 

### 💡 Próximos pasos

- 
```

No es obligatorio completar todos los apartados.
Si durante un día solamente se realizó una modificación pequeña, se pueden utilizar únicamente las secciones necesarias.

# 📸 Registro fotográfico

Las fotografías utilizadas en esta bitácora se encuentran almacenadas en:

```text
Fotos/
```

Se recomienda utilizar nombres simples y descriptivos.

Por ejemplo:

```text
14-08-2026_atom_general.jpg
14-08-2026_harnero.jpg
14-08-2026_sensores_laser.jpg
15-08-2026_servomotores.jpg
15-08-2026_electronica.jpg
```

Para evitar problemas con las rutas de GitHub se recomienda:

* No utilizar espacios en los nombres.
* Utilizar `_` o `-` para separar palabras.
* Utilizar nombres cortos.
* Mantener la fecha al comienzo cuando sea posible.
